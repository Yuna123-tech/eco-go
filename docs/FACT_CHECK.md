# 생물 정보 사실 확인 기록 (2026-10-31)

웹 검색으로 생물 정보를 하나씩 확인했습니다. 확인된 내용만 남겼고, 생물마다 `js/data.js`의 `sources`에 출처를 붙였습니다. 출처는 앱의 생물 상세 화면 「🔗 출처」에서도 볼 수 있습니다.

## 확인 원칙
- 출처에서 확인된 내용만 남기고, 확인되지 않은 숫자·일화·지역 주장은 빼거나 "~라는 설명이 있다"처럼 바꾸었습니다.
- 출처마다 내용이 다르면 그 사실을 함께 적었습니다 (예: 한국호랑이 마지막 포획 연도).
- 생물이 게임 속 어느 바이옴에 나오는지는 **게임 설정**이며, 그 장소의 실제 관찰 기록이 아닙니다. 앱에도 이렇게 표시합니다.
- 보스 "수정이", "초량이"는 게임을 위해 만든 **상상 속 캐릭터**로 표시했습니다. "부캉이"는 2026년 9~10월 북항에 실제로 나타난 흑상어입니다.

## 아직 남은 한계
- 이 작업 환경에서는 국립생물자원관, 위키백과, GBIF 같은 사이트에 직접 접속할 수 없어 **검색 결과 요약**으로 확인했습니다. 일부 출처는 신문 기사와 블로그입니다.
- 문제은행(`js/questions.js`)의 교과 개념 문제(자석, 물의 상태 변화, 기체 등)는 교과서 표준 개념이라 따로 출처를 달지 않았습니다. 출판사마다 표현이 다를 수 있습니다.
- 수업에 쓰기 전에 선생님이 한 번 더 검토하시는 것을 권합니다.
